# Ofício, uma loja que revela ser uma demonstração do Undersoft Commerce

Site estático (React 19 + Vite 8, GSAP, Motion). Começa como uma loja de barbearia (Ofício) na sua própria identidade e, depois do rodapé, revela que é uma demonstração e mostra o que o Undersoft Commerce faz, já na identidade da Undersoft.

```bash
npm install
npm run dev       # desenvolvimento
npm run build     # produção (cliente + servidor + pré-render em dist/)
npm run preview   # servir o dist/
```

O conteúdo vive em `src/data/`. As capacidades mostradas no capítulo do sistema indicam, em cada uma, o que existe de facto no Undersoft Commerce e o que é simulação.
